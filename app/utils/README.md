&gt; Transforming 5 crore Tamil Nadu smartphones into AI-powered traffic enforcement cameras

## 🌟 Features

- **🤖 AI-Powered Detection**: YOLOv8 + EasyOCR for 97.9% accurate violation detection
- **📱 Mobile-First**: Streamlit web app works on any smartphone
- **⚡ Real-Time Processing**: 45-second end-to-end challan generation
- **💰 Citizen Rewards**: 10% of fine value as FASTag/metro recharge
- **🔒 Legally Valid**: Auto-generated e-challans with QR code payment
- **🗺️ Tamil Nadu Optimized**: Custom-trained on TN license plates and traffic patterns
